# 架构

avdkit 按公共模型、平台与执行原语、环境探测、领域门面和出口分层。依赖始终从上层指向下层，平台差异集中在单独边界内。

## Workspace

Rust workspace 按依赖方向分层：

- `model` 只包含可序列化的公开数据类型、稳定错误码和暂定产品名派生函数，不执行 I/O。
- `platform` 集中处理主机平台、默认路径和工具文件名。其他 crate 不直接判断目标操作系统。
- `process` 提供带超时、取消和进程组清理的异步子进程执行原语，工具驱动通过它运行外部命令。
- `avdfs` 提供保留未知行和键顺序的 INI 文档读写原语。
- `drivers` 描述官方工具调用、输出清洗和错误分类，不包含设备领域决策。
- `env` 生成一次性的环境快照，并从快照推导能力状态。
- `core` 提供线程安全的 `Kit` 门面、查询、长任务句柄和创建计划编译。
- `cli` 提供 `environment`、`capabilities`、`refresh` 三个基础查询命令及带 `schema_version` 的 JSON 输出。
- `ffi` 定义语言绑定边界，当前转出核心门面和公共模型。

依赖只能从出口层指向基础层。`model` 不依赖 workspace 内的其他 crate。Rust 调用方只需要依赖品牌包 `avdkit`（`core`）。
